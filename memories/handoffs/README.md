# Handoffs

Use one file per unfinished task so parallel agents never overwrite each other:
`YYYY-MM-DD-<task>-<agent>.md`.

Keep only what another agent needs to resume:

- objective and scope;
- completed work with file paths;
- current blockers or open decisions;
- next deterministic action;
- latest verification evidence;
- assumptions that still need validation.

Do not paste transcripts or private reasoning. Remove obsolete handoffs after the
outcome is folded into stable memory, docs, specs, or code.
