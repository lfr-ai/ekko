# Support

- **Bug or feature request** — open an [issue](https://github.com/lfr-ai/ekko/issues/new/choose) using the template.
- **Question or usage help** — check the [README](README.md) and [`docs/`](docs/) first, then open an issue.
- **Security vulnerability** — do not open a public issue; follow [SECURITY.md](SECURITY.md).
- **Contributing** — see [CONTRIBUTING.md](CONTRIBUTING.md).

Ekko is maintained on a best-effort basis; there is no response-time guarantee.
