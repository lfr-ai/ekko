# Domain glossary

- **Audio stream** — desktop audio frames flowing into speech recognition.
- **Transcript** — timestamped speech-to-text text emitted by an audio source.
- **Conversation** — ordered interaction containing messages and transcripts.
- **Message** — one participant's contribution to a conversation.
- **Prompt version** — immutable prompt content selected by registry metadata.
- **PII policy** — profile controlling anonymization before text crosses an AI boundary.
- **Source** — producer of a transcript, such as system or microphone audio.
